# Capstone: Follow the Money

**A case file with a traced transaction chain and a legal map**

## Goal
Produce a professional investigation file on a synthetic or public case, from crime type to money trail to legal route.

## How it works
The capstone is built **one phase at a time**. Each phase is the mini project at the end of a lab, so finishing the labs means you are already finishing the capstone. Post after each phase if you like (see `SHOWCASE.md`).

| Phase | Name | From | What you deliver |
|---|---|---|---|
| 1 | **Case study brief** | Lab 01 | A one-page anatomy of a public case: actors, infrastructure, money, what led to the arrest. |
| 2 | **Peel-chain tracer** | Lab 02 | A script and a graph image that finds collection wallets and a peel chain in synthetic transactions. |
| 3 | **Forensic mini-report** | Lab 03 | A report on the practice disk image: hashes, deleted file recovered, chain of custody. |
| 4 | **Legal map** | Lab 04 | A one-page map from the case to offences, cooperation routes and AML obligations. |

## Final assembly
Merge phases 1 to 4 into one case file using `templates/case-file.md`, with evidence numbers linking claims to evidence.

## Gemini layer (optional, encouraged)
Use Gemini to extract entities from a **public** press release into a structured file; every claim must have an exact quote verified in code (Forge Lab 03).

## Definition of done
- [ ] Runs or reads from a clean clone of your own repo
- [ ] README using `templates/student-project-readme.md`
- [ ] Synthetic or public data only; no secrets, no personal data
- [ ] States honestly what AI helped with and how it was checked
- [ ] Added one thing of your own beyond the labs (a feature, test, diagram or writeup)
