# Ledger: Cybercrime

How cybercrime works, how it is investigated, and how the law responds. This track is about **understanding crime and following evidence**, and it stands on its own (OSINT is a separate track).

| # | Lab | You will learn |
|---|---|---|
| 01 | [Cybercrime anatomy](01-cybercrime-anatomy) | The criminal ecosystem: fraud, ransomware, money mules, the economics |
| 02 | [Crypto tracing basics](02-crypto-tracing-basics) | How blockchains work for investigators, detect a peel chain with Python |
| 03 | [Digital forensics basics](03-digital-forensics-basics) | Hashing, disk images, recovering deleted files, chain of custody |
| 04 | [Cybercrime law](04-cybercrime-law) | Budapest Convention, UN cybercrime convention, cross-border cooperation, AML |
