# Aegis: LLM Security

Large language models are now inside search, code editors, customer support and agents with real tools. That creates a new attack surface. This track teaches you to **attack practice systems and defend real ones**.

| # | Lab | You will learn |
|---|---|---|
| 01 | [OWASP LLM Top 10](01-owasp-llm-top10) | The map of LLM risks and how to talk about them |
| 02 | [Prompt injection](02-prompt-injection) | Direct and indirect injection, play Gandalf, build and break a guarded app |
| 03 | [RAG and agent security](03-rag-and-agent-security) | Poisoned documents, excessive agency, least privilege |
| 04 | [Red-teaming](04-red-teaming) | Automated scanning with garak and promptfoo, writing findings |

Practice rules: only attack the practice targets provided here or systems you own. See `ETHICS.md`.
