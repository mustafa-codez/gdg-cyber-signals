# Capstone: A Bio-Cyber Notebook

**Sequences, networks and data protection in one reproducible notebook**

## Goal
Show that security thinking works on biological data: pattern-finding, graph analysis and responsible data handling.

## How it works
The capstone is built **one phase at a time**. Each phase is the mini project at the end of a lab, so finishing the labs means you are already finishing the capstone. Post after each phase if you like (see `SHOWCASE.md`).

| Phase | Name | From | What you deliver |
|---|---|---|---|
| 1 | **Sequence similarity notebook** | Lab 01 | Alignment and k-mer similarity on public sequences, plus the same idea on script snippets. |
| 2 | **Network chokepoint analyzer** | Lab 02 | Graph analysis of a toy protein network and an attack graph: shortest path and betweenness. |
| 3 | **Bio-data protection plan** | Lab 03 | A k-anonymity check on a synthetic table and a one-page protection plan. |
| 4 | **Docking reproducibility report** | Lab 04 | A documented docking run (or a redocking test) with versions, parameters and checksums. |

## Final assembly
Combine into one Jupyter or Colab notebook with a short narrative and a data-protection note.

## Gemini layer (optional, encouraged)
Use Gemini to **explain** a result or a function in plain language; re-run the code and check the numbers yourself. Never upload real personal samples.
