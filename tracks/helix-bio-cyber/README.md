# Helix: Bio-Cyber

Where biology meets security and data. This track is **computational only**: sequences, networks, data protection. No wet-lab content.

| # | Lab | You will learn |
|---|---|---|
| 01 | [Sequences as signals](01-sequences-as-signals) | DNA/protein sequences, alignment with Biopython, the same ideas applied to malware-style similarity |
| 02 | [Graph algorithms](02-graph-algorithms) | Shortest paths and centrality on biological networks and attack graphs |
| 03 | [Bio-data security](03-bio-data-security) | Why genomic and neural data are special, pseudonymisation, k-anonymity, regulation |
| 04 | [Docking intro](04-docking-intro) | What molecular docking is and how to run a reproducible beginner example |

New here? Read [why this track exists](../../docs/why-bio-cyber.md) first.

Everything uses public or synthetic data. See `ETHICS.md`.

## Capstone
Every lab ends with a mini project that is one phase of this track's capstone: **A Bio-Cyber Notebook**. See [`CAPSTONE.md`](CAPSTONE.md).
