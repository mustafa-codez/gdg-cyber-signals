# Scout: OSINT

**Open-Source Intelligence** = turning publicly available information into verified knowledge. This track is about **method and verification**, not just tools, and it is independent of the Ledger (cybercrime) track.

| # | Lab | You will learn |
|---|---|---|
| 01 | [Methodology](01-methodology) | The intelligence cycle, source grading, documentation, OPSEC |
| 02 | [Image and media verification](02-image-and-media-verification) | Reverse image search, metadata, archiving |
| 03 | [Geolocation](03-geolocation) | Locate a photo from visual clues, sun and shadow analysis, map queries |
| 04 | [Deepfake verification](04-deepfake-verification) | Detect and verify AI-manipulated media, provenance standards |

Read `ETHICS.md` first. OSINT without ethics becomes stalking.

## Capstone
Every lab ends with a mini project that is one phase of this track's capstone: **Verification Dossier**. See [`CAPSTONE.md`](CAPSTONE.md).
