# Capstone: Verification Dossier

**A verified, documented OSINT investigation**

## Goal
Answer one public-interest question with documented sources, graded evidence and a confidence statement.

## How it works
The capstone is built **one phase at a time**. Each phase is the mini project at the end of a lab, so finishing the labs means you are already finishing the capstone. Post after each phase if you like (see `SHOWCASE.md`).

| Phase | Name | From | What you deliver |
|---|---|---|---|
| 1 | **Collection plan and log** | Lab 01 | A requirement, a collection log and source grading for a public question. |
| 2 | **Verification write-up** | Lab 02 | A debunk or confirmation of a public image or video, with reverse-search results, metadata and archives. |
| 3 | **Geolocation walkthrough** | Lab 03 | The reasoning chain for locating a practice image, with at least two independent matches. |
| 4 | **Deepfake verification guide** | Lab 04 | A one-page guide for family or team: how to verify suspicious media and the second-channel rule. |

## Final assembly
Assemble a single dossier: question, method, evidence table (with hashes and archive links), findings, confidence.

## Gemini layer (optional, encouraged)
Use Gemini only to **summarise public sources you already collected**; check every claim against the source and grade it yourself. Never ask it to identify people.

## Definition of done
- [ ] Runs or reads from a clean clone of your own repo
- [ ] README using `templates/student-project-readme.md`
- [ ] Synthetic or public data only; no secrets, no personal data
- [ ] States honestly what AI helped with and how it was checked
- [ ] Added one thing of your own beyond the labs (a feature, test, diagram or writeup)
