# Contributing

Contributions of every size are welcome: typo fixes, new labs, better explanations, dead-link fixes.

## Add a lab

1. Copy `templates/LAB_TEMPLATE.md` into the right track folder as `NN-short-name/README.md`.
2. Fill every section. If a command needs a particular OS or version, say so.
3. Test every snippet on a clean machine or container.
4. Link any source you used, and put new links in `RESOURCES.md`.
5. Open a pull request using the template.

## Style

- Plain language first, jargon second. Define terms the first time.
- Short sentences. Explain *why* before *how*.
- Code blocks must be copy-paste runnable.
- Never include real secrets, real personal data, or live malware.
- Follow `ETHICS.md`.

## Report a problem

Use the issue templates in `.github/ISSUE_TEMPLATE`.
