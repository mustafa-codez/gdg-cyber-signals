# Google's Free (and Underrated) Resources

A hand-picked list of **free or free-to-start** Google resources that fit this chapter's tracks. Items marked **[Gem]** are the ones many students never hear about.

> Free tiers, student offers and product names change often. Check each page for current limits and terms. This list is community-made, not an official Google resource.

## 1. Start here: accounts and perks

## 2. Learn security and cloud

## 4. Blue team and threat intelligence
| Resource | Link | Why |
|---|---|---|
| **VirusTotal** (owned by Google) | https://www.virustotal.com | Free file, URL, domain and IP lookups; free API with limits. Check an indicator in seconds **[Gem]** |
| Safe Browsing | https://safebrowsing.google.com | Understand how Google flags phishing and malware sites |
| Safe Browsing site status | https://transparencyreport.google.com/safe-browsing/search | Look up whether a URL is flagged **[Gem]** |
| Google Threat Intelligence | https://cloud.google.com/security/products/threat-intelligence | Mandiant and VirusTotal intelligence; read the public reports and product docs |
| Google Security Operations (SecOps) | https://cloud.google.com/security/products/security-operations | See how a cloud SIEM and SOAR are designed |
| Mandiant Academy | search "Mandiant Academy free courses" | Free on-demand incident-response and threat-intel courses (availability varies) **[Gem]** |
| Google Security Blog | https://security.googleblog.com | Practical write-ups from the security team |
| Google Project Zero blog | https://googleprojectzero.blogspot.com | Deep vulnerability research, great advanced reading |

## 5. Open-source security tools by Google
| Resource | Link | Why |
|---|---|---|
| **OSV** (Open Source Vulnerabilities database) | https://osv.dev | Search known vulnerabilities by package **[Gem]** |
| OSV-Scanner | https://github.com/google/osv-scanner | Scan your projects' dependencies for known vulnerabilities, free **[Gem]** |
| **deps.dev** | https://deps.dev | Explore a package's dependencies, versions and advisories **[Gem]** |
| OSS-Fuzz | https://github.com/google/oss-fuzz | Continuous fuzzing of open-source projects; learn how fuzzing finds bugs |
| OpenSSF Scorecard | https://github.com/ossf/scorecard | Rate the security health of a repository |
| Google Cloud Security Command Center docs | https://cloud.google.com/security-command-center | Learn cloud posture management concepts |

These pair well with Forge Lab 04 ("Build safely").

## 13. Which resource fits which track
| Track | Best Google free resources |
|---|---|
| **Watchtower** (blue team) | VirusTotal, Safe Browsing status, Google Security Blog, SecOps and Threat Intelligence docs, SRE and Secure Systems books, Cloud Shell, Mandiant Academy |
| **Ledger** (cybercrime) | VirusTotal, Dataset Search, Takeout (your own data) for forensics practice, Google Scholar, Threat Intelligence reports |
| **Scout** (OSINT) | Lens, Earth, Fact Check Explorer, Alerts, Advanced Search, Scholar, Trends, SynthID |
| **Aegis** (LLM security) | SAIF, Responsible AI, PAIR Guidebook, AI Studio, Gemini API, NotebookLM, Google CTF for general skills |
| **Helix** (bio-cyber) | AlphaFold DB, Dataset Search, Kaggle, Colab, Earth Engine (for data skills) |
| **Forge** (Build with AI) | AI Studio, Gemini API and cookbook, Gemini CLI, Colab, Cloud Shell, OSV-Scanner, deps.dev |
